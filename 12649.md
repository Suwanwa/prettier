## Description

Fixes #12649 (wrapping before an inline tag).

With `proseWrap: "always"`, wrapping an inline MDX tag onto a new line turns it into a JSX block when reparsed. This changes the paragraph structure and makes the second formatting pass insert a blank line. Keep the whitespace immediately before an inline tag unbroken, allowing the preceding words to wrap instead.

The regression covers component and HTML tags, inline code, links, emphasis, blockquotes, lists, and an existing block component. It runs with all three `proseWrap` settings. The original example fails before the fix and remains one paragraph afterward.
