## Description

Fixes #18189.

An empty `lineSuffix` followed by `lineSuffixBoundary` currently forces a group to break and flushes an empty suffix. For example, `group(["a", lineSuffix(""), lineSuffixBoundary, line, "b"])` prints `"a\n\nb"` even when `"a b"` fits.

Ignore structurally empty suffixes when checking whether a group fits and when queuing suffixes for printing. Use the existing `cleanDoc` utility so cursor markers and other meaningful Doc commands remain intact. Regression tests cover empty strings, arrays, nested arrays and indents, a pending real comment, and cursor positions.
