## Description

Fixes #16759.

Removing parentheses from a mapped type's `keyof` constraint changes how TypeScript copies optional/readonly modifiers. For example, `{ [Key in (keyof Input)]: boolean }` requires properties that were optional in `Input`, while the unparenthesized form preserves them. This is still observable with TypeScript 6.0.3.

Preserve an existing outer pair of parentheses in this constraint context. The source check excludes comments and distinguishes parentheses around the whole constraint from parentheses around only the operand. Unparenthesized constraints stay unparenthesized.

Before the fix, 8 parser regression checks failed, and a TypeScript compiler reproduction showed diagnostic 2741 disappearing after formatting. After the fix, all 40 regression checks pass and the compiler diagnostic is preserved.
