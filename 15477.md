## Description

Fixes #15477.

An indented `markdown` or `md` template in an object property, call argument or array could collapse to one line. A second format then treated it as unindented Markdown and expanded it differently. Keep the opening line break for indented Markdown so the indentation choice stays stable across formatting runs. Unindented templates keep their existing behavior.

The regression covers all three contexts. It failed on the unchanged source before this fix; the original reported example also failed a direct idempotence assertion.
