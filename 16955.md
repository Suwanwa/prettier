## Description

Fixes #16955.

With `experimentalTernaries`, a parenthesized ternary in a member chain can break after its opening parenthesis while keeping the closing parenthesis on the content line. Apply the existing closing-parenthesis break at the outer indentation level when the ternary is given extra indentation. This covers ordinary and optional member access and keeps short expressions on one line.

The new explicit-output regression failed 26 parser checks before the fix and passed all 78 checks afterward. Four existing experimental-ternary snapshots are updated only to reflect aligned closing parentheses in the same member-chain contexts.
