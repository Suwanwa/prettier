## Description

Addresses the binary and logical expression cases in #7746.

A leading own-line comment inside parentheses around a left operand can move to the enclosing expression when the parentheses are removed. This changes the grouping and produces different output on a second format. Preserve parentheses around that operand, keep its comment inside them, and avoid flattening away that boundary. The parentheses check delegates to the binary printer so existing precedence parentheses are not duplicated.

The regression covers nested binary expressions, remainder, assignments, calls, matching and different precedences, logical expressions, block comments, sequences, inline comments, and ignored expressions, with both operator positions. This does not resolve the separate conditional-only and member-expression cases from the issue discussion.
