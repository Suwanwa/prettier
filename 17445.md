## Description

Fixes #17445.

With `experimentalTernaries`, a nested ternary in a JSX attribute can insert a blank line before the closing brace. When the expression has a trailing comment, each formatting pass adds another blank line.

The JSX-context check was using the current ternary's grandparent, even after finding the outermost conditional expression. Use the parent of that chain's JSX expression container instead, so nested attribute expressions receive the same layout as their outer expression. The production change is one line.

Regression fixtures cover nested alternates with and without a trailing comment, a nested consequent, and an actual JSX child expression. Both the default and experimental ternary options are tested. The two new snapshots were inspected; no existing snapshots were changed.
