## Description

Fixes #9570.

A comment between a function name and its type parameters can move between different attachment sites on repeated formatting. Attach that comment consistently to the type parameters and print the separating space for named functions. Anonymous generic functions retain their existing spacing.

The regression includes the reported `declare function` example, declarations and expressions, inline and own-line block comments, line comments, multiple comments, and an anonymous control.
