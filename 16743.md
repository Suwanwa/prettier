## Description

Fixes #16743.

When a SCSS map value ends with multiple line comments, Prettier can insert the trailing comma between the comments. Defer the whole trailing comment run until after the parent prints its comma, and keep that run with its value when parsing an existing trailing comma. Single-comment and block-comment behavior stays unchanged.

The regression failed 8 checks before the fix and passes all 24 checks afterward. It covers one, two and three comments, input with and without a comma, and `trailingComma: "all"` / `"none"`. No existing snapshots are changed.

- A separate 96-case matrix checked comma placement and second-format equality for root/nested maps, tabs/spaces, widths 20/80 and all three trailing-comma settings: passed.
